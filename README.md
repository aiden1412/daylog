# 하루 시간기록 (daylog)

스톱워치 방식으로 하루 활동을 기록하고, 기록 사이의 빈 시간(자투리 시간)을 자동으로 계산하는 휴대폰용 웹앱입니다.

- 앱 주소: https://aiden1412.github.io/daylog/
- 기록 데이터: 비공개 저장소 `daylog-data`에 날짜별 파일로 저장 (`days/YYYY-MM-DD.json`)
- 이 저장소에는 앱 코드만 있으며 개인 기록이나 토큰은 들어 있지 않습니다.

## 사용 방법
1. [▶ 시작] → 일하기 → [■ 종료]
2. 분류 선택 + 한 일 입력 → [저장]
3. 저녁에 [지금 마침]으로 하루 범위 확정

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성과 디자인 |
| `app.js` | 스톱워치, 자투리 계산, GitHub 저장 |
| `manifest.webmanifest`, `icons/` | 휴대폰 홈 화면 설치 정보 |
| `sw.js` | 인터넷이 끊겨도 앱이 열리도록 앱 파일 보관 |

## 데이터 형식 (`days/2026-11-23.json`)
```json
{
 "date": "2026-11-23",
 "dayStart": "06:50",
 "dayEnd": "22:10",
 "entries": [
  { "id": "…", "start": "09:00", "end": "10:15", "category": "업무", "memo": "예산안 검토", "at": 0 }
 ],
 "deleted": []
}
```
